# خبراء هونداي وفورد — Workshop Manager Android

نسخة تأسيسية قابلة للبناء عبر GitHub Actions. التطبيق عربي ويدعم RTL ويعمل محلياً دون اتصال بالإنترنت.

## ما يعمل في هذه النسخة 0.1.0
- لوحة رئيسية وإحصاءات أولية.
- إنشاء ملفات العملاء مع رقم هاتف أساسي فريد.
- إنشاء ملفات السيارات وربط كل سيارة بعميل، مع VIN فريد.
- إنشاء أمر إصلاح وربط العميل والسيارة وحفظ قراءة العداد عند الزيارة.
- إضافة قطع إلى سجل المخزون.
- عرض أحدث السجلات.
- قاعدة SQLite محلية على الهاتف.
- تطبيع أرقام الهاتف العربية والهندية واللاتينية إلى أرقام لاتينية، وتطبيع VIN إلى أحرف كبيرة دون فواصل.

## قرارات البيانات المطبقة
- العميل يُعرّف برقم الهاتف، ويمكن أن يمتلك عدة سيارات.
- لكل سيارة VIN فريد وسجل أوامر إصلاح مستقل.
- قراءة العداد تحفظ في أمر الإصلاح، وتُحدّث قراءة السيارة الحالية دون إنقاصها.
- لا يتم نقل ملكية السيارة تلقائياً عند تعارض الهاتف وVIN؛ يلزم إجراء نقل ملكية صريح في مرحلة لاحقة.

## البناء على GitHub
1. ارفع **محتويات هذا المجلد** إلى جذر المستودع `WorkshopManagerAndroid`، وليس ملف ZIP نفسه.
2. تأكد أن الملف موجود في المسار `.github/workflows/android.yml`.
3. من تبويب Actions شغّل `Build Workshop Manager APK` أو ادفع Commit إلى فرع `main`.
4. بعد نجاح البناء، افتح تشغيل Workflow ثم قسم Artifacts ونزّل `WorkshopManager-debug-apk`.

## بيئة البناء المثبتة
- Android Gradle Plugin 9.3.1 (مستقر ومتوافق مع Gradle 9.5.0)
- Gradle 9.5.0
- Kotlin Gradle Plugin 2.4.21 عبر دعم Kotlin المدمج في AGP 9
- JDK 17
- compileSdk 37 / targetSdk 36 / minSdk 26

## ما لم يكتمل بعد
هذه ليست النسخة النهائية التجارية. المراحل التالية تشمل: قواعد منع تكرار الهاتف وVIN مع معالجة التعارض حسب قواعد المشروع كاملة، نقل الملكية بسجل موثق، تحرير وحذف آمن، تفاصيل التشخيص والإصلاح والعمالة والقطع المستخدمة، الفواتير والطباعة، حسابات العملاء والديون، تقارير الأرباح، صلاحيات الموظفين، الصور، النسخ الاحتياطي المشفر، ثم المزامنة المركزية عند توفر الإنترنت.

لا تضع بيانات عملاء حقيقية حساسة في هذه النسخة التجريبية قبل إضافة تسجيل الدخول والصلاحيات والنسخ الاحتياطي والحماية المطلوبة.
