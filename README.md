# خبراء هونداي وفورد — Workshop Manager Android

تطبيق Android عربي لإدارة ورشة السيارات، يعمل محلياً دون اتصال دائم بالإنترنت، ويدعم واجهة RTL وقاعدة بيانات SQLite داخل الجهاز.

## الحالة الحالية

إصدار التطبيق في هذا الفرع هو **0.7.5** (`versionCode` 12). التطبيق يضم إدارة العملاء والسيارات وأوامر الإصلاح والدفعات والمخزون والفواتير والصور، إضافة إلى المستخدمين والصلاحيات والموارد البشرية والإعدادات.

## اللغة

التطبيق عربي خالص في الوقت الحالي، والواجهة مصممة من اليمين إلى اليسار. لا يوجد اختيار لغة أخرى في هذا الإصدار.

## أبرز الوظائف الحالية

- ملفات العملاء والسيارات وربط السيارة بعميل مع التحقق من رقم الهيكل VIN.
- استقبال السيارات والبحث بالهاتف أو اللوحة أو VIN.
- أوامر الإصلاح، المهام، الفنيون، المواعيد، الدفعات، الأرصدة، وقطع الغيار.
- التقاط أو اختيار عدة صور مع معاينتها وحذف الصور غير المناسبة قبل إرفاقها.
- إنشاء الفواتير والتقارير بصيغة PDF ومشاركتها أو طباعتها؛ صور السيارة وأمر الإصلاح لا تُدرج في الفاتورة.
- إدارة المستخدمين وصلاحياتهم والموارد البشرية.
- مهلة تسجيل الخروج التلقائي، معرض الصور، والنسخ الاحتياطي والاستعادة المحليان.
- تشغيل محلي دون اعتماد على اتصال دائم بالإنترنت.

## البناء على GitHub

1. افتح تبويب Actions في المستودع.
2. شغّل `Build Workshop Manager APK` أو ادفع Commit إلى `main` أو `feature/reception-permissions`.
3. بعد نجاح سير العمل، نزّل Artifact المناسب من صفحة التشغيل.

يتطلب البناء Android Gradle Plugin 8.13.2 وGradle 8.13 وKotlin 2.2.21 وJDK 17 وAndroid SDK 36. يتطلب بناء Release الموقّع أسرار التوقيع المحددة في إعدادات GitHub Actions؛ لا تضع ملف Keystore أو كلمات مروره في المستودع.

## إعدادات التطبيق ومعلوماته

تتضمن الإعدادات مهلة تسجيل الخروج التلقائي ومعرض الصور. صفحة معلومات التطبيق تعرض الإصدار واللغة المدعومة وملاحظات الخصوصية. يمكن فتحها برابط التطبيق `workshopmanager://about`.

## تنبيه الخصوصية

قاعدة البيانات محلية، والنسخ الاحتياطية المشفرة محفوظة بصيغة `.json.enc` باستخدام مفتاح تشفير في Android Keystore. يجب استعادة النسخ داخل التطبيق وعلى الجهاز الذي أنشأها؛ لا تشارك ملفات النسخ أو مساحة التطبيق مع جهات غير موثوقة.

## تحديثات مطلوبة قبل الاستخدام التجاري

- اختبارات آلية لقاعدة البيانات والاقتراحات وإنشاء الفواتير PDF.
- اختبار استعادة النسخ والترقية على بيانات تجريبية متعددة الإصدارات.
- مراجعة التعارضات القائمة لرقم اللوحة وقاعدة البيانات عند ترحيل بيانات قديمة.
- مراجعة الضرائب والخصومات والعمالة وتفاصيل الفاتورة.
- مزامنة اختيارية آمنة بين الأجهزة والفروع.

## خارطة الطريق

تتضمن الرؤية المستقبلية دعم تخصصات متعددة للورش، وسجل فني تراكمي للسيارات، وتحليلات تشغيلية، ومساعداً فنياً اختيارياً تحت إشراف الفني، ومزامنة مركزية ولوحة ويب. هذه أفكار مستقبلية وليست إقراراً بأن وظائفها منفذة حالياً. لا ينبغي تضمين مفاتيح خدمات الذكاء الاصطناعي السرية داخل تطبيق Android.
